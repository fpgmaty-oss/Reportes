terminal Cómo Publicar en GitHub Pages

Paso 1: Crea un repositorio en GitHub (ej: Reportes-Tienda).

Paso 2: En la terminal de esta carpeta, ejecuta:

git init
git add .
git commit -m "Sistema de Reportes y Cajas Autopick"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/Reportes.git
git push -u origin main

Paso 3: En GitHub entra a Settings > Pages.

Paso 4: En Branch selecciona main y carpeta / (root) y haz clic en Save.

¡Listo! En 1 minuto tu aplicación estará accesible para todos en internet.
